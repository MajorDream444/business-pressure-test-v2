# User Flow

## Sprint 1 Flow

```text
Landing Page
-> Quiz
-> Score
-> Diagnosis
-> Result Screen
```

## Landing Page

Purpose: establish the promise and start the diagnostic.

Required content:

- Business Pressure Test V2 / Business MRI positioning
- one clear value statement
- start button

Do not add complex marketing sections in Sprint 1.

## Quiz

Purpose: collect enough signal to diagnose business pressure.

The quiz should:

- ask focused business-readiness questions
- use consistent answer options
- score every answer
- keep the user moving quickly

## Score

Purpose: translate answers into a clear readiness score.

The score should:

- be easy to understand
- map into a diagnosis band
- prepare the user for the result reveal

## Diagnosis

Purpose: explain the result without overwhelming the user.

The diagnosis should include:

- score band
- short diagnosis summary
- pressure pattern
- top leaks
- immediate next move

## Result Screen

Purpose: make the user feel seen and give a useful next step.

Sprint 1 result screen should show:

- score
- diagnosis band
- explanation
- top leaks
- next moves

Sprint 1 should not submit to Airtable or capture payment.
